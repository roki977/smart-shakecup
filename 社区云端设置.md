# 社区：开启云端模式

默认是**本机模式**：发的帖子、评论只存在这台设备的浏览器里，演示时不依赖网络。
想让所有人看到同一个社区，需要一个存数据的地方。这里用 Supabase（免费版就够）。

## 1. 建项目

1. 打开 https://supabase.com ，用 GitHub 账号登录，New project（区域选离中国近的，比如 Singapore / Tokyo）。
2. 建好后进 Project Settings → API，记下两样：
   - Project URL，形如 `https://abcdefgh.supabase.co`
   - `anon` `public` key（一长串）。这个 key 本来就是给网页公开用的，权限由下面的规则限制。

## 2. 建表

左侧 SQL Editor → New query，粘贴下面整段，点 Run：

```sql
create table posts (
  id uuid primary key default gen_random_uuid(),
  created_at timestamptz not null default now(),
  data jsonb not null check (octet_length(data::text) < 20000)
);
create table comments (
  id uuid primary key default gen_random_uuid(),
  created_at timestamptz not null default now(),
  post_id uuid not null references posts(id) on delete cascade,
  data jsonb not null check (octet_length(data::text) < 2000)
);
create table likes (
  post_id uuid not null references posts(id) on delete cascade,
  client_id text not null check (length(client_id) < 40),
  created_at timestamptz not null default now(),
  primary key (post_id, client_id)
);

alter table posts enable row level security;
alter table comments enable row level security;
alter table likes enable row level security;

-- 所有人能看；能发帖、评论、点赞、取消点赞；不能改、不能删别人的帖子
create policy "read posts" on posts for select using (true);
create policy "add posts" on posts for insert with check (true);
create policy "read comments" on comments for select using (true);
create policy "add comments" on comments for insert with check (true);
create policy "read likes" on likes for select using (true);
create policy "add likes" on likes for insert with check (true);
create policy "remove likes" on likes for delete using (true);
```

## 3. 填进网站

打开 `community-config.js`，填上第 1 步的两样：

```js
window.COMMUNITY_CONFIG = {
  supabaseUrl: 'https://abcdefgh.supabase.co',
  anonKey: '这里贴 anon key'
};
```

推送到 GitHub 后，社区页底部会显示“云端模式”。连不上时网站会自动退回本机内容，并在底部提示。

## 说明

- 没有登录系统：昵称是自己填的，存在浏览器里。点赞用每台设备一个随机编号去重。黑客松演示够用；正式上线要加登录和内容审核。
- 帖子不能编辑、删除；要删的话在 Supabase 后台 Table Editor 里手动删。
- 带“示例”标记的几条是写在代码里的演示内容（`community.js` 的 `seedPosts`），不在数据库里。
